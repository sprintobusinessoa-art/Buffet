# مشروع وارد — إدارة فواتير المشتريات والمخزون

تم بناء هذا المشروع بهندسة معمارية مفصولة الطبقات (Decoupled Architecture) لضمان سهولة التعديل والصيانة دون تشابك أو تعطل أي جزء عند تعديل جزء آخر:

- `css/tokens.css`: متغيرات الألوان، الخطوط، الظلال، والحدود (تعديل اللون الرئيسي هنا يحدث التطبيق بالكامل).
- `css/layout.css`: هيكل الصفحة العام (RTL)، القائمة الجانبية، والتجاوب مع الشاشات الصغيرة.
- `css/components.css`: أنماط البطاقات، شريط الخطوات، عدسة الكاميرا، وحقول الإدخال.
- `js/utils/formatters.js`: دوال نقية لتنسيق الأرقام والعملات والتواريخ العربية بدون أي اعتماد على DOM.
- `js/utils/calculations.js`: دوال الحسابات المالية النقية (تكلفة القطعة، إجمالي الصنف، مطابقة الفاتورة).
- `js/data/catalog.js`: بيانات المتاجر، الموردين، وكتالوج الأصناف الافتراضي.
- `js/state/store.js`: مخزن الحالة المركزي (Single Source of Truth) بنمط Pub/Sub.
- `js/components/*.js`: مكونات واجهة مستقلة تماماً، كل مكون مسؤول عن شاشة واحدة فقط.
- `js/app.js`: نقطة التشغيل الرئيسية وتفويض الأحداث (Event Delegation).
